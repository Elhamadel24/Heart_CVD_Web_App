About this integration

This project's Power BI report cannot currently be published via Power BI's "Publish to Web" or embedded through Power BI Embedded, since those require an organizational/university Microsoft account or Power BI Pro licensing. Instead, the four report pages are exported as high-resolution static images directly from the original .pbix file, so the dashboard is always viewable — fully offline and without any Microsoft authentication. The original, unmodified .pbix file is bundled with this project and can be downloaded above and opened in Power BI Desktop at any time. See powerbi_embed_future.md in the project root for how this could be upgraded to a live embedded report later.
