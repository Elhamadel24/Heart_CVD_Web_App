How the best model was selected

Every model listed above was trained on the exact same stratified 80/20 train-test split of the cleaned dataset, using an identical preprocessing pipeline (standard scaling for numeric features, one-hot encoding for categorical features). Each was scored on the held-out test set using Accuracy, Precision, Recall, F1-score and ROC-AUC. The model with the highest ROC-AUC — the metric most robust to class imbalance — was selected as the production model, with F1-score as a tie-breaker. This selection happens automatically inside train_model.py; nothing is assumed in advance.
