ℹ️ About This Project

CardioAI is an end-to-end cardiovascular disease analytics platform built on a real 270,064-record clinical dataset.

📁 Dataset

The dataset was extracted directly from the project's own Power BI data model (Where_Heart_Data_Becomes_Insight.pbix) and contains {{ "{:,}".format(dataset_info.n_rows) }} patient records across {{ dataset_info.n_columns }} original columns, with {{ dataset_info.missing_values }} missing values and {{ dataset_info.duplicate_rows_ignoring_id }} duplicate rows.

Preprocessing

Missing-value & duplicate checks, BMI feature engineering from height/weight, one-hot encoding of categorical features, standard scaling of numeric features, stratified 80/20 train-test split.

2️⃣

Training

Logistic Regression, Decision Tree, Random Forest and Gradient Boosting were each trained on identical data and evaluated on the same held-out test set.

3️⃣

Deployment

The winning pipeline (preprocessing + model) is serialized with joblib and loaded once by the Flask app — no retraining happens at request time.

📈 Power BI Dashboard

The original Power BI report, "Where Heart Data Becomes Insight," is included unmodified in this project (data/dashboard.pbix) and its four pages are displayed as static exports on the Power BI Analytics page — no Microsoft account, Power BI Pro, or Fabric license required.
